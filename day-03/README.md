## 102. 二叉树的层序遍历

- 解法：BFS + 队列；每轮先 `sz = q.size()` 拍快照，`for` 循环只处理本层 sz 个节点；O(n) 时间 / O(n) 空间
- 推导：同层节点 = 距根步数相同 = BFS 定义；队列先进先出天然分层；不拍 sz 快照会把下层节点混进本层
- 易错：`q.size()` 在循环中动态变化，必须提前存 sz
- 变体：107 层序 II（反转）、199 右视图、103 锯齿形

## 206. 反转链表

- 解法：三指针 `prev/cur/nxt` 原地掉头，先存 `nxt` 再改 `cur->next`；O(n) 时间 / O(1) 空间
- 推导：O(1) 空间 → 必须原地改指针 → 掉头会断链 → 先存后继 → 三针齐步
- 易错：先掉头再存 nxt 会断链；空链表/单节点直接返回
- 变体：92 反转链表 II、25 K 个一组翻转、234 回文链表

## 155. 最小栈

- 解法：主栈 `st` + 同步最小值栈 `minSt`（第 i 层 = st 前 i+1 个元素的最小值）；四操作全 O(1) 时间 / O(n) 空间
- 推导：栈只能 O(1) 看顶 → 极值信息必须随高度记账 → 平行栈
- 易错：push 用 `<=`（重复最小值都记录，否则连续 pop 两个最小值会出错）；pop 时仅当 `st.top() == minSt.top()` 才同步弹
- 变体：232 用栈实现队列、739 每日温度（单调栈）
