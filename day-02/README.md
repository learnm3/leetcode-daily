## 62. 不同路径

- 解法：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`（上方 + 左方），第一行第一列全 1；滚动数组压到 O(n) 空间
- 推导：每个格子的走法数 = 被谁走到（上方/左方）的走法数之和；终点答案可用组合数 `C(m+n-2, m-1)` 交叉验证
- 易错：滚动数组内层循环从 `j=1` 开始，否则 `dp[-1]` 越界（UBSan 报错）
- 变体：63 不同路径 II、64 最小路径和、221 最大正方形

## 209. 长度最小的子数组

- 解法：滑动窗口——右指针扩张，窗口和 ≥ target 时左指针收缩并记录最短长度；O(n) 时间 / O(1) 空间
- 推导：数组全为正数是单调性前提（右移和变大、左移和变小）；每个元素最多进/出窗口各一次 → O(n)
- 易错：收缩要用 `while`（可能连续扔多个）；全程没达标返回 0
- 变体：3 无重复字符的最长子串、76 最小覆盖子串、239 滑动窗口最大值

## 215. 数组中的第 K 个最大元素

- 解法：维护大小为 k 的**小顶堆**，堆顶 = "前 k 名的门槛（最小者）"；超员就 pop 堆顶；O(n log k) 时间 / O(k) 空间
- 推导："第 k 大" = "前 k 名里的最后一名" = 门槛；新人比门槛强就顶替，弱就忽略 → 无需完整排序
- 易错：小顶堆是 `priority_queue<int, vector<int>, greater<int>>`；`pq.size() > k` 比较前把 size_t 强转 int
- 变体：703 数据流中的第 K 大元素、347 前 K 个高频元素、973 最接近原点的 K 个点
