## 48. 旋转图像（顺时针 90°）

- 解法：先**转置**（沿主对角线），再**每行反转**；时间复杂度 O(n²)、空间 O(1)
- 推导：旋转矩阵公式 `(i,j) → (j, n-1-i)`；转置+反转恰好等价；逆时针 90° = 转置+每列反转（或每行反转后转置）；180° = 行反转+列反转
- 易错：转置内层循环从 `j=i+1` 开始（否则换两遍等于没换）
- 变体：54 螺旋矩阵、59 螺旋矩阵 II

## 200. 岛屿数量

- 解法：遍历网格，遇到 `'1'` 计数并把整片岛用 DFS 淹没为 `'0'`；时间 O(mn)、空间 O(mn)（最坏栈深）
- 易错：DFS 边界判**列用 `n`、行用 `m`**（`j >= n`，写成 `j >= m` 在长方形网格会漏岛/越界）
- 变体：695 岛屿最大面积、130 被围绕的区域、463 岛屿周长

## 146. LRU 缓存

- 解法：**哈希表 + 双向链表**，get/put 均 O(1)；链表头 = 最近使用，链表尾 = 最久未使用
- 易错：构造函数必须初始化 `cap`（漏初始化是未定义行为）；用虚拟头/尾哨兵避免空链表特判；put 已有 key 时先更新值再搬到头部；超出容量时删尾部节点并同步删哈希
- 变体：460 LFU 缓存（加频率维度）
